# 검수 작업 폴더

**정하는 것**: 사람이 손으로 채우는 검수 산출물을 두는 자리.

**왜 따로 두는가**: `scripts/reco/bench/out/` 은 "문서가 인용하는 수치의
기준선" 이라 일부러 커밋합니다. 검수 시트는 성격이 다릅니다 — 사람이 몇 시간에
걸쳐 채우는 작업물이고, 중간 상태가 저장소에 오갈 이유가 없습니다.
`raw_data/` 와 같은 방식으로 폴더는 남기고 내용은 추적하지 않습니다.

---

## 여기 있는 것

| 파일 | 무엇 |
|---|---|
| `review_sheet.tsv` | 원본 시트. `make review-sheet TOP=N` 이 만듭니다 |
| `review_sheet.csv` | 구글 스프레드시트용. `make review-csv` 가 만듭니다 |
| `review_guide.txt` | 무엇을 적는지 안내 |
| `dictionary.tsv` | 쓸 수 있는 재료 이름 목록 (536종) |

## 작업 순서

```bash
make review-sheet TOP=800     # 시트 생성 (채운 내용을 지웁니다 — 주의)
make review-csv               # 구글 스프레드시트용 CSV 로 내보내기
```

구글 스프레드시트에서 `파일 → 가져오기 → 업로드` 로 `.csv` 를 열고
**E열(결정)만** 채웁니다. 셋 중 하나입니다.

```
재료명   기존 재료로 잇는다     예) 매실액 → 매실청
X       재료가 아니다 (도구·용기·소모품)
NEW     사전에 없는 새 재료     예) 밥 · 육수
```

다 채우면 `파일 → 다운로드 → 쉼표로 구분된 값(.csv)` 으로 받아서

```bash
make review-apply SHEET="~/Downloads/받은파일.csv"          # 미리보기
make review-apply SHEET="~/Downloads/받은파일.csv" WRITE=1   # 시드에 반영
```

**한 번에 다 채우지 않아도 됩니다.** 빈 칸은 건너뜁니다.

## 주의

`make review-sheet` 를 다시 돌리면 **채운 내용이 날아갑니다.** 작업 중에는
돌리지 마십시오. 구글 스프레드시트에 사본이 있으면 안전합니다.
