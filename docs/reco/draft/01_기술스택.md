## Roadmap (프로토 범위 외)

- 🔴 ~~RDB / Vector: PostgreSQL + pgvector~~ — **이미 도입** (SQLite 미사용)
- 🔴 ~~Online Store: Redis~~ — **컨테이너 가동 중** (코드 미연결)
- **분석 엔진: DuckDB + 테이블 포맷: Parquet**
  - 도입 시점: 로그가 **수천만 행**을 넘거나, 분석을 PostgreSQL 밖으로 빼야 할 때
  - 대체 대상: PostgreSQL 직접 쿼리
  - 현재 규모: DB **약 520 MB** (09-03 실측 513~531 MB · ~~552 MB~~) ·
    8주 누적 로그 투영 +183 MB ≈ **0.70 GB**
  - ⚠️ 로그를 파일로 빼면 `event_log ↔ recommendation_log` 조인(`request_id`)이
    끊긴다. 그 조인이 학습의 전부이므로 **빼려면 조인을 먼저 해결해야 한다**
- **DataFrame: Polars 또는 pandas**
  - 도입 시점: 배치가 메모리에 안 들어가거나, Streamlit 이 못 받는 형태를 그릴 때
  - 대체 대상: 순수 Python(정규화) · SQL 집계 · numpy(벡터)
  - ⚠️ 지금 넣으면 세 트랙이 각자 다른 도구로 같은 집계를 하게 된다
- Feature Store: Feast
  - 도입 시점: 랭킹 모델 2개 이상 또는 피처 50개 초과 시
  - 대체 대상: `features.py` 수동 관리
- 모델 서빙: NVIDIA Triton
  - 도입 시점: 모델 3개 이상 동시 서빙 시
  - 대체 대상: FastAPI 직접 로드
- 테이블 포맷: Apache Iceberg
  - 도입 시점: 데이터 재현성·삭제 요청 대응 필요 시
  - 대체 대상: Parquet 폴더
- 시퀀스 모델: SASRec
  - 도입 시점: 유저당 상호작용 10건 이상 확보 시
  - 대체 대상: ALS + 콘텐츠

  - 도입 시점: 배치 스케줄링 필요 시
  - 대체 대상: Makefile
