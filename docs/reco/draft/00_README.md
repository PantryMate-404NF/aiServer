## 문서가 낡지 않게

문서에 숫자를 쓰면 시간이 지나며 실제와 어긋납니다.
코드는 테스트가 깨져서 알려주는데 문서는 아무 일도 일어나지 않습니다.

그래서 검사를 만들어 뒀습니다.

```
make doc-check
```

문서에 적힌 숫자가 데이터베이스·코드와 맞는지 대조합니다.
**문서의 수치를 고쳤으면 이 명령을 같이 돌려 주세요.**
