# 온보딩 맛 선호 측정용 음식 목록

> 작성자: 박재우 · 작성일: 2026-09-04

맛 6축: [매움, 짠맛, 단맛, 신맛, 감칠맛, 기름짐] 각 0~1

유저가 이 목록에서 좋아하는 음식을 고르면 **고른 음식들의 맛 벡터 평균**이
그 사람의 취향(taste_vec)이 된다. 그래서 이 목록이 곧 측정 도구다.
20개가 다 비슷한 맛이면 몇 개를 골라도 정보가 나오지 않는다.

## 점수는 손으로 매기지 않았다

각 음식의 **재료**를 엔진과 같은 함수(`app/services/normalize` 의 `p5_flavor.aggregate`)에
넣어 계산했다. 재료별 맛 기여값(`seeds/ingredient_flavor.yaml`)을
역할(주·양념·선택) 가중 평균한 값이다. 나중에 실제 레시피의 `flavor_vec` 과 같은 기준이 된다.

③절의 재료로 언제든 다시 계산할 수 있다. 시드가 바뀌면 값도 바뀌므로 **재계산이 정본**이다.

🔴 재료 구성은 **요리 상식이지 실측이 아니다.** 리포트에 '실측'으로 쓰지 말 것.
   크롤 데이터로 검증되면 실제 레시피 `flavor_vec` 으로 교체한다.

🔴 재료명은 `seeds/ingredient.csv` 536종에 있는 것만 쓴다. 이름이 한 글자라도 다르면
   맛 기여값을 못 찾아 그 재료가 0 으로 계산된다.
