## 2. 재현 명령

```bash
uv run python scripts/eval_recommend_mock.py                 # 12 페르소나 + 시나리오 + 지연시간
uv run python scripts/eval_recommend_mock.py --persona 1003  # 한 명만
```

- 출력은 stdout. 한글이 깨지면 `PYTHONUTF8=1`.
- 탐색 슬롯의 항목과 위치는 실행마다 다름(SystemRandom). 점수·개인화 슬롯·판정 지표는 같음(V-08).
